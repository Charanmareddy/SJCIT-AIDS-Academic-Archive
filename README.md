## 📚 Complete Semester Overview

### 🔹 [4th Semester Core](./4th%20Sem/)
* Core engineering fundamentals, mathematical foundations, data structures, and foundational algorithms.

### 🔹 [5th Semester Core](./5th%20Sem/)
* Machine learning algorithms, database management systems, artificial intelligence principles.

### 🔹 [6th Semester Core](./6th%20Sem/)
* Deep learning concepts, software engineering, specialized electives.
* Lab manuals, practical guides, and domain mini-project documentation.

### 🔹 [7th Semester Core & Electives](./7th%20Sem/7th%20Sem/)

* **Business Analytics (BA):** Module textbooks, CIE 3 papers, tutorial keys, and managerial analytics.
* **Computer Network Resources (CNR):** Module notes (1–5), model papers, tutorial solutions, and technical reports.
